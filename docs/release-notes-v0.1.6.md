# v0.1.6 更新说明

2026-10-09

- 新增快速网站搜索，可在地址栏输入站点名和关键词，直接搜索已识别的网站。
- 新增阅读模式，支持正文字号、背景主题和按网站自动开启。
- 扩充内置搜索引擎，新增搜狗、360 搜索、Google、Yahoo、DuckDuckGo 和 Ecosia。
- 优化书签管理，左滑显示编辑、删除图标；支持新建文件夹和选择保存位置。
- 优化书签编辑界面、输入栏和返回动画。
- 优化多页面概览，宽屏每行显示两个缩略图，标题居中，支持上滑进入概览；统一多页面按钮图标线宽。
- 地址栏新增蓝色网页加载进度线，延长提示时间，加载完成后隐藏；下拉刷新触发后立即回弹。
- 为多页面、切换标签、下拉刷新、新建页和首页编辑等操作增加震动反馈，调整反馈触发时机。
- 减少弹层和标签切换中的整体变淡，改善过渡动画与面板背景。
